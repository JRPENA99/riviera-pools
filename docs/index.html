The Process

Six phases.One schedule.

Every project begins with a design consultation and a fixed proposal. Construction then moves through six defined phases.

How we work
01

Excavation & Steel

The pool is excavated, formed and reinforced with a steel rebar cage built to your design.

02

Plumbing & Electrical

Lines, equipment, lighting and automation are set before the shell is placed.

03

Gunite

The structural shell is shot in gunite — any shape, any size the site allows.

04

Tile & Coping

Waterline tile and coping define the finish: stone, glass, mosaic and accent tile.

05

Plaster

The interior finish is applied and the pool is filled for the first time.

06

Clean Up

Every phase is cleaned up as we go — the site is handed back ready to swim.
